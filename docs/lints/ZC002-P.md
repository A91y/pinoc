# ZC002-P `unchecked-length-before-cast`

deny · likely · ZC (zero-copy layout)

An account's data borrowed through an `*_unchecked` accessor with no length guard. A shorter account than expected is read past its end.

## What counts

- **Fires on:** `borrow_unchecked`, `borrow_unchecked_mut`, `borrow_data_unchecked` and `borrow_mut_data_unchecked` on an account.
- **Cleared:** a `data_len()` read on that account, a `.len()` test on the borrowed bytes, or handing the bytes to a crate-local function that tests their length. Bytes handed to a function outside the crate are that function's to bound.

## Limits

- **Order:** a guard anywhere in the handler counts, even one after the borrow.
- **Guard size:** the compared size is not checked against `size_of::<T>()`.
- **Delegated accounts:** a delegated account is left alone.

## Fix

Check `account.data_len() >= size_of::<T>()` before the unchecked borrow.

## Flagged

```rust
pub fn cast(program_id: &Address, accounts: &[AccountView]) -> ProgramResult {
    let [vault, ..] = accounts else {
        return Err(ProgramError::NotEnoughAccountKeys);
    };
    if vault.owner() != program_id {
        return Err(ProgramError::IllegalOwner);
    }
    let data = unsafe { vault.borrow_data_unchecked() };
    let _state = VaultState::from_bytes(data)?;
    Ok(())
}
```

## Not flagged

```rust
pub fn cast(program_id: &Address, accounts: &[AccountView]) -> ProgramResult {
    let [vault, ..] = accounts else {
        return Err(ProgramError::NotEnoughAccountKeys);
    };
    if vault.owner() != program_id {
        return Err(ProgramError::IllegalOwner);
    }
    if vault.data_len() < VaultState::LEN {
        return Err(ProgramError::InvalidAccountData);
    }
    let data = unsafe { vault.borrow_data_unchecked() };
    let _state = VaultState::from_bytes(data)?;
    Ok(())
}
```
