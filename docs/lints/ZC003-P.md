# ZC003-P `missing-repr-c`

deny · definite · ZC (zero-copy layout)

A `ShankAccount` or `ShankType` struct, read zero-copy, without `#[repr(C)]` or `#[repr(transparent)]`. Rust's default layout may reorder fields, breaking the byte mapping the client relies on.

## What counts

- **Fires when:** a struct derives `ShankAccount` or `ShankType` and has neither attribute.
- **Placement:** the finding is at the struct's first attribute, so an allow directly above the item covers it.

## Fix

Add `#[repr(C)]`.

## Flagged

```rust
#[derive(ShankAccount)]
pub struct Vault {
    pub amount: u64,
}
```

## Not flagged

```rust
#[repr(C)]
#[derive(ShankAccount)]
pub struct Vault {
    pub amount: u64,
}
```
